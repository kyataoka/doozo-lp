# Doozo プライバシーポリシー

**制定日: 2026年9月23日**
**最終改定日: 2026年9月23日**

本プライバシーポリシー（以下「本ポリシー」といいます）は、Hiroki Kataoka（以下「当方」といいます）が提供する iOS アプリ「Doozo」（以下「本アプリ」といいます）における利用者の情報の取り扱いについて定めるものです。本アプリをご利用いただく前に、本ポリシーをお読みください。

本アプリは、利用者が選んだ写真・動画だけを表示し、端末を他の人に渡しても、選んでいない写真へ進めないようにするためのアプリです。本アプリは利用者のアカウント登録を必要とせず、当方は写真や履歴を預かるサーバーを運用していません。無料プランでは本アプリ内に広告を表示します（2.3 をご覧ください）。

## 1. 事業者情報

- 事業者名: Hiroki Kataoka（個人開発者）
- お問い合わせ先: kyataoka.deve@gmail.com
- 対象アプリ: Doozo（iOS）

## 2. 当方が取得する情報

### 2.1 写真・動画と履歴 — 当方へは送信されません

本アプリは、利用者が iOS の写真ピッカーで選んだ写真・動画を表示し、見せた写真のまとまりを「履歴」として端末内に保存します。**当方が、写真・動画そのもの、どの写真を選んだか、履歴の内容を受け取ることは一切ありません。**

- 写真ライブラリへのフルアクセスを許可された場合、本アプリは選ばれた写真の識別子だけを端末内に保存し、表示のたびに写真ライブラリから読み込みます。
- フルアクセス以外（限定アクセス、許可しない、未決定）の場合、選ばれた写真・動画を本アプリ内の保存領域にコピーします。コピーは端末のバックアップ（iCloud バックアップ等）から外しています。
- 他のアプリ（写真アプリなど）の共有から本アプリに写真・動画を送った場合も、本アプリ内の保存領域にコピーします。このコピーも端末のバックアップから外しています。
- 履歴（有料プラン「Doozo Plus」の機能です）には、見せた日時、並び順、利用者が付けた名前・ピン留めなどの情報が含まれ、いずれも端末内に保存されます。
- 見せている間に本アプリが裏に回った時刻と回数は、閉じた後にお知らせを表示するために端末内に一時的に保存されます。

### 2.2 購入に関する情報

有料プランの購入は、Apple の App内課金（In-App Purchase）だけを通じて行われます。本アプリは、購入状態を確認するために端末内で Apple（StoreKit）に問い合わせます。当方が、利用者のクレジットカード番号等の決済手段の情報を受け取ることはありません。当方は課金管理のための第三者サービスを利用していません。

### 2.3 広告の表示に関する情報

無料プランでは、本アプリ内に広告を表示します。広告の配信には Google の広告サービス「Google AdMob」（Google LLC）の SDK を利用しており、広告の配信・表示回数の計測・不正防止のために、以下のような情報が Google に送信されます。

- IP アドレスから推定される大まかな位置（国・地域の水準）
- デバイス情報（デバイスの種別、OS バージョン等）、広告の表示・タップ等の状況、および広告 SDK の動作に関する診断情報

本アプリは iOS の「トラッキングの許可」を求めず、広告識別子（IDFA）を利用しません。パーソナライズされていない広告を要求します。欧州経済領域（EEA）・英国等では、同意管理ツールを利用していないため、制限付きの広告のみが配信されます。

**広告 SDK が、利用者の写真・動画や履歴を読み取ることはありません。** 当方が広告に関して受け取るのは、表示回数・収益等の集計値のみです。有料プラン（広告なし、Doozo Plus）をご利用の場合、広告 SDK は初期化されず、広告のための情報送信も行われません。

Google における情報の取り扱いは、Google のプライバシーポリシー（https://policies.google.com/privacy ）によります。

### 2.4 利用状況の記録（アプリ改善のための計測）

本アプリは、どの機能が使われたか（例: 手渡しを始めた、プランの画面を開いた）を、あらかじめ定めた項目名と値だけで記録します。送信には Google アナリティクス for Firebase（Google LLC）を利用します。

写真・動画、履歴の名前、枚数、日時が送信されることは一切ありません。広告のための信号は送信せず、個人を識別する情報や広告識別子とも結び付けません。この記録は、本アプリの設定（「プライバシー」内の「利用状況の送信」）からいつでも停止できます。本アプリは、クラッシュ情報を収集するサービスを利用していません。

### 2.5 ご意見・お問い合わせの送信

本アプリ内の「ご意見・お問い合わせ」から送信いただいた場合に送信されるのは、選択いただいた種別（不具合・要望・その他）と入力いただいた本文、アプリのバージョン・iOS のバージョン・端末の機種名のみです。個人を識別する情報を含まないため、当方から返信することはできません。保存先は Google Cloud Firestore（Google LLC）です。送信は、本物の本アプリからのものであることを確かめる仕組み（Firebase App Check）を通じて行います。保存場所は東京リージョン（asia-northeast1）です。

## 3. 利用目的

- 2.2 の情報: 有料プランの提供、有料機能の有効化・無効化、購入の復元
- 2.3 の情報: 無料プランを広告収益によって提供するための、広告の配信・表示・測定および不正防止（Google において利用されます）

## 4. 第三者への提供・委託

当方は、取得した情報を第三者に販売・貸与することはありません。また、法令に基づく場合を除き、第三者へ提供することはありません。

本アプリの提供のために、以下の事業者のサービスを利用しています。

- Apple Inc.（App Store / In-App Purchase）: 決済処理、サブスクリプションの提供・更新・解約
- Google LLC（Google AdMob）: 無料プランにおける広告の配信・測定
- Google LLC（Firebase: Google アナリティクス / Cloud Firestore / App Check）: 2.4 の利用状況の集計、および 2.5 のお問い合わせ内容の保管

これらの事業者のサーバーは日本国外に所在する場合があります。

## 5. データの保存場所と保存期間

- 写真の識別子、写真・動画のコピー、履歴は、利用者の端末内（本アプリ専用の保存領域）に保存され、当方のサーバーには保存されません。
- 履歴は Doozo Plus をご利用の間だけ保存され、利用者が削除するまで、または設定「履歴を自動で削除」に従って削除されるまで保存されます。履歴を削除すると、コピーした写真・動画も削除されます。
- Doozo Plus をご利用でない場合、履歴は保存されず、コピーした写真・動画は見せ終えた後に削除されます。Doozo Plus が終了した場合（無料トライアルの終了を含みます）は、履歴とコピーをすべて削除します。
- 他のアプリの共有から送られた写真・動画のうち、見せなかったものや Doozo Plus でない間に送られたものは、本アプリを開いた時に削除されます。
- 本アプリを端末から削除すると、端末内の履歴とコピーはすべて削除されます。写真アプリの写真は削除されません。
- 2.5 のお問い合わせ内容は、東京リージョンの Google Cloud Firestore に、対応と改善に必要な期間保管し、不要になったものは削除します。
- 2.3 の広告関連情報、2.4 の利用状況の保存期間は、Google の定めるところによります。

## 6. 利用者の選択

- 写真ライブラリへのアクセス: iOS の「設定」から、いつでも変更できます。フルアクセス以外でも本アプリは使えます（写真はコピーされます）。
- 履歴の削除（Doozo Plus）: 本アプリ内で個別に、または設定の「履歴をすべて削除」でまとめて削除できます。
- 利用状況の記録: 設定の「利用状況の送信」から、いつでも停止できます。
- 広告: 有料プラン（広告なし、Doozo Plus）をご購入いただくと、広告は表示されず、広告 SDK も初期化されません。

## 7. 生体認証（Face ID 等）の取り扱い

有料プラン「Doozo Plus」のロック機能では、ロックの解除に端末の生体認証（Face ID 等）を利用します。照合は端末の OS 内で完結し、本アプリが顔などの生体情報そのものを取得・保存・送信することは一切ありません。本アプリは、OS から「認証に成功したか否か」の結果のみを受け取ります。
